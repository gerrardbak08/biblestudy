**아키텍처 설계:**
```
┌─────────────────────────────────────┐
│      Next.js App Router (15.2.3)    │
├─────────────────────────────────────┤
│  (auth) group → Login                 │
│  (dashboard) group → Admin/Leader     │
├─────────────────────────────────────┤
│  Middleware (역할 기반 라우팅)         │
├─────────────────────────────────────┤
│  NextAuth v5 beta (Session/JWT)      │
├─────────────────────────────────────┤
│  Prisma ORM + PostgreSQL/Supabase     │
├─────────────────────────────────────┤
│  Server Actions (Zod validation)      │
├─────────────────────────────────────┤
│  Tailwind CSS + shadcn/ui + Recharts  │
└─────────────────────────────────────┘
```

**3역할 분리 설계:**
| Role | 권한 | 페이지 |
|------|------|--------|
| ADMIN | 전체 관리 | /admin/* (대시보드, 리더관리, 보고서 조회) |
| DEPT_HEAD | 부서 모니터링 | /dept/* (부서 대시보드, 소속 리더/보고서) |
| LEADER | 자신의 학습자 관리 | /leader/* (학습자 관리, 보고서 제출/조회) |
