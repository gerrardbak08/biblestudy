교회 성경공부 관리 플랫폼 (Next.js App Router + Supabase/Prisma + Server Actions, shadcn/ui)

**3개 역할:**
- ADMIN (목회자, 50-60대, PC): 전체 통계/차트, 리더/부서/커리큘럼 CRUD
- DEPT_HEAD (기관장, 40-50대, 혼용): 부서 리더 모니터링, 보고서 조회
- LEADER (진행자, 20-40대, 스마트폰): 매주 교육생별 보고서 제출 (핵심 반복 작업)

**핵심 도메인:** Course → Section → Lesson 커리큘럼 계층, 보고서(출석/이해도/참여도/돌봄 평가 포함)

**UX 핵심 개선 방향 (2026-04-02 분석):**
- 리더: 보고서 폼 12개 필드 → 필수만 노출, 커리큘럼 3단계 선택 접기
- 관리자: 통계 카드만 있고 액션 없음 → "이번 주 미제출 리더" 카드 추가
- 기관장: 리더 목록에 이번 주 제출 여부 배지 없음 → 인라인 상태 배지

**생략 가능 기능:** 평가 3개 항목, "다음 계획" 텍스트 필드 — 접기 권장, 삭제는 아님

**Why:** UX 분석 결과 기술 구현은 완료됐으나 사용 마찰이 남아있어 채택률 저하 우려
**How to apply:** 새 기능 제안 시 역할별 실제 사용 빈도와 모바일/PC 환경을 먼저 고려할 것
